# Science Explorer Hub

Build an interactive educational web application called AI Science Lab for learners aged approximately 11–16.

The application should feel like a virtual science laboratory and exploration experience, not a conventional textbook website. It should combine interactive simulations, visual explanations, guided experimentation, scientific facts, and short quizzes.

The experience should be visually engaging, modern, polished, and slightly magical while remaining scientifically accurate.

CORE EXPERIENCE

Create a home page called AI Science Lab with three large interactive laboratory modules:

Chemical Reaction Lab

DNA & Genetics Lab

Natural Disasters Lab

Each lab should have its own visual identity, interactive simulation area, learning section, and quiz.

Use a consistent navigation system so learners can move between:

Science Lab Home

Individual Labs

Learn

Experiment

Quiz

Progress

Add a subtle laboratory/futuristic aesthetic with glass-like panels, scientific diagrams, particles, smooth animations, interactive cards, and depth.

Avoid making the entire application look cyberpunk or neon. Use a sophisticated science-museum / futuristic laboratory aesthetic with different visual themes for each lab.

LAB 1 – CHEMICAL REACTION LAB

Theme

"Molecular Alchemy: From Reactants to Products"

Create an interactive laboratory where learners can combine different chemical compounds and observe how they can form new substances.

The central area should contain an interactive reaction chamber.

Learners should be able to:

Select a compound from a collection of reactants.

Drag and drop compounds into the reaction chamber.

Combine compatible reactants.

Start the reaction.

Observe an animated transformation.

See the resulting product.

Explore the molecular/structural representation before and after the reaction.

Visualisation

When compounds are mixed:

Show molecules moving toward each other.

Animate bonds breaking/forming where appropriate.

Transition from reactant molecules to product molecules.

Display the chemical equation.

Display a simplified molecular/structural diagram.

Highlight which atoms are rearranged.

Show the product name.

Do not simply show a static image.

The learner should visually understand:

Reactants → Reaction → New Product

Include examples that are age-appropriate and scientifically accurate.

For example:

Acid + Base → Salt + Water

Iron + Oxygen → Iron Oxide

Hydrogen + Oxygen → Water

Where appropriate, clearly distinguish between:

Mixing

Physical change

Chemical reaction

Learning Panel

For every experiment provide:

What are the reactants?
What happens during the reaction?
What is the product?
What happens to the atoms?
Is this a physical or chemical change?

Include a simplified molecular explanation suitable for the target age group.

Structure Explorer

Add a toggle:

"View Molecules"

This switches between:

Simple learner-friendly representation

Molecular/structural diagram

Allow learners to rotate or inspect the molecular representation where practical.

Safety

Include a small virtual-lab safety section explaining that the simulation is educational and does not provide instructions for performing hazardous chemical experiments in real life.

LAB 2 – DNA & GENETICS LAB

Theme

"Genome Garden: Create a Living Legacy"

Give this lab a more magical/fantasy-inspired visual style while keeping the underlying genetics scientifically grounded.

Imagine a magical genetics garden where DNA strands appear as glowing biological structures growing inside a futuristic laboratory.

The learner should be able to explore how traits can be inherited from two parents.

Parent Selection

Create two fictional parent creatures/characters.

For example:

Parent A

Eye colour

Hair/fur colour

Pattern

Height/body size

Wing type

Horn type

Tail type

Parent B

Eye colour

Hair/fur colour

Pattern

Height/body size

Wing type

Horn type

Tail type

Do NOT make this about real human appearance ideals.

Use fictional creatures so the activity focuses on genetics rather than judging human physical characteristics.

Allow learners to select traits for Parent A and Parent B.

DNA Visualisation

When the learner selects traits:

Show a large animated DNA double helix.

Allow the learner to explore:

DNA

Genes

Chromosomes

Alleles

Dominant/recessive inheritance at an age-appropriate level

Visually connect:

DNA → Gene → Trait

When the learner clicks a trait, highlight the corresponding fictional gene/allele representation.

Create an Offspring

Add a large button:

"Create Offspring"

When clicked:

Animate DNA strands from both parents.

Show genetic information being inherited.

Randomly select appropriate allele combinations.

Generate an offspring.

Display the resulting fictional creature.

Give the offspring:

A unique name

Visual traits

Trait inheritance explanation

Simplified genotype information

Phenotype explanation

For example:

Inherited from Parent A: Pattern
Inherited from Parent B: Eye characteristic
New combination: Wing type

Make the result visually exciting, like discovering a new fantasy creature.

Genetics Probability

Where appropriate, include a simple interactive probability section.

For example:

"How likely is the offspring to inherit this trait?"

Use simple visual probability representations rather than complicated mathematics.

Add a "Try Another Offspring" button so learners can observe that different offspring can inherit different combinations.

Clearly explain that the simulation is a simplified genetics model and that real genetics is much more complex.

LAB 3 – NATURAL DISASTERS LAB

Theme

"Planet Earth: Forces of Nature"

Create an interactive simulation environment representing Earth.

The learner can explore different natural disasters:

Earthquake

Volcano

Tsunami

Hurricane/Cyclone

Flood

Wildfire

Do not portray disasters in a frightening or graphic way.

The goal is to understand the science behind the event, how it develops, and how people can prepare safely.

Interactive Earth

Create a stylised interactive Earth/landscape.

Allow the learner to select a disaster.

When selected, transition into a simulation.

Earthquake Simulation

Show:

Tectonic plates

Plate movement

Stress building

Fault movement

Ground shaking

Allow the learner to adjust variables such as:

Magnitude

Distance from epicentre

Depth

Then simulate how the ground responds.

Explain:
What causes earthquakes?
What is an epicentre?
What are seismic waves?

Volcano Simulation

Show:

Magma chamber

Magma rising

Pressure building

Eruption

Allow learners to adjust simplified variables such as:

Pressure

Magma movement

Visualise the relationship between the underground magma system and the eruption.

Explain:
Why do volcanoes erupt?
What is magma?
What is lava?

Tsunami Simulation

Show:

Ocean

Seafloor

Underwater earthquake

Wave generation

Wave movement toward the coast

Allow learners to observe how wave height and energy can change as waves approach shallower water.

Hurricane/Cyclone Simulation

Show:

Warm ocean

Rising moist air

Rotation

Spiral cloud structure

Storm development

Explain the basic conditions that contribute to tropical cyclones.

Flood Simulation

Create a landscape with:

River

Rainfall

Ground

Houses/infrastructure

Allow rainfall intensity to change and show how water levels respond.

Wildfire Simulation

Show a stylised landscape and explain how:

Heat

Dry vegetation

Wind

Fuel availability

can influence wildfire spread.

Keep the simulation educational rather than graphic.

LEARNING SYSTEM

Every lab should follow the same learning cycle:

EXPLORE → EXPERIMENT → OBSERVE → UNDERSTAND → QUIZ

Create a persistent progress indicator.

Example:

LAB 1
✓ Explore
✓ Experiment
○ Learn
○ Quiz

The learner should be able to revisit experiments.

QUIZ SYSTEM

Every laboratory should have a short interactive quiz after the learning experience.

Create approximately 8–10 questions per lab.

Use a mixture of:

Multiple choice

True/False

Identify the diagram

Predict the outcome

Match concepts

Scenario-based questions

Questions should test understanding rather than memorisation.

After each answer:

Show whether it is correct.

Provide a short explanation.

Visually highlight the relevant concept.

At the end show:

Your Science Lab Result

Display:

Score

Concepts understood

Concepts to revisit

Lab completion status

Do not make the result overly competitive.

AI SCIENCE ASSISTANT

Add an optional small assistant called:

Lab Assistant

The assistant should help learners understand what they are seeing.

Examples:

"What happened to the molecules?"

"Why did the offspring inherit this trait?"

"Why did the earthquake create waves?"

The assistant should provide short, age-appropriate explanations rather than simply giving quiz answers.

Include suggested questions learners can click.

VISUAL DESIGN

Use a high-quality modern educational interface.

Overall style:

Futuristic science museum

Interactive laboratory

Clean glass panels

Soft gradients

Scientific diagrams

3D-inspired objects

Smooth transitions

Particle effects used sparingly

Depth and layered environments

Responsive animations

Clear typography

Each laboratory should have its own visual identity:

Chemical Lab

Molecular structures, laboratory glassware, particles, molecular bonds.

DNA Lab

DNA helixes, biological patterns, magical garden elements, glowing organisms, fantasy creatures.

Natural Disaster Lab

Earth, terrain, atmospheric effects, geological layers, water and weather simulations.

Avoid excessive neon, generic AI imagery, or repetitive cyberpunk aesthetics.

The interface should feel like a premium interactive science museum.

UX REQUIREMENTS

Make the application intuitive enough that a learner can explore without teacher assistance.

Use:

Tooltips

Hover interactions

Click-to-explore elements

Drag-and-drop where useful

Animated transitions

Reset experiment button

Replay simulation button

"What am I seeing?" explanations

Clear navigation

Provide both:
Quick Explore
and
Learn More

so learners can choose how deeply they want to explore.

RESPONSIVE DESIGN

The application should work well on:

Desktop

Laptop

Tablet

Prioritise desktop/laptop because the simulations require interactive space.

TECHNICAL EXPECTATIONS

Build the application as a functional interactive web experience rather than a collection of static pages.

Use reusable components for:

Lab cards

Simulation panels

Molecule visualisation

DNA visualisation

Quiz cards

Progress indicators

Simulation controls

Keep the data for:

HOME PAGE HERO

Create a strong opening section:

AI SCIENCE LAB

"Explore. Experiment. Discover."

Subheading:

Step inside a virtual science laboratory and discover the hidden forces behind chemistry, genetics, and our planet.

Then show the three laboratory entrances as interactive cards.

Each card should have:

Animated visual

Lab name

Short description

"Enter Lab" button

The overall experience should feel like the learner is entering a science adventure, with each lab offering a different world to explore.
